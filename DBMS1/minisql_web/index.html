📖 SQL 语法速查（与本项目实际支持一致）

提示: 支持多条语句用 ; 分隔；建议每条语句以分号结尾。

数据库: SHOW DATABASES; | CREATE DATABASE db; | DROP DATABASE db; | USE db;

表: SHOW TABLES; | DESC t; | DROP TABLE t; | RENAME TABLE old TO new;

创建表: CREATE TABLE t (id INT PRIMARY KEY AUTO_INCREMENT, name VARCHAR(50) NOT NULL, age INT DEFAULT 18);

修改表: ALTER TABLE t ADD col INT; | ALTER TABLE t DROP COLUMN col; | ALTER TABLE t MODIFY col VARCHAR(100); | ALTER TABLE t RENAME COLUMN old TO new;

插入/更新/删除: INSERT INTO t (c1,c2) VALUES (v1,v2); | UPDATE t SET c1 = c1 + 1 WHERE id = 1; | DELETE FROM t WHERE id = 1; | TRUNCATE TABLE t;

基础查询: SELECT * FROM t; | SELECT DISTINCT col FROM t;

WHERE 条件: 支持 = != <> < > <= >= AND OR (...) LIKE BETWEEN ... AND ... IN (...) NOT IN (...) IS NULL IS NOT NULL

排序/分页: ORDER BY col ASC|DESC | LIMIT n | LIMIT n OFFSET m

聚合/分组: COUNT/SUM/AVG/MAX/MIN | GROUP BY | HAVING

JOIN: SELECT o.id, p.name FROM orders o JOIN products p ON o.product_id = p.id;

事务: BEGIN; ... COMMIT; / ROLLBACK;

索引: CREATE INDEX idx ON t(col); | CREATE UNIQUE INDEX idx ON t(col); | SHOW INDEXES FROM t; | DROP INDEX idx ON t;

外键: ALTER TABLE t ADD CONSTRAINT fk FOREIGN KEY(col) REFERENCES ref(id) ON DELETE SET NULL; | SHOW FOREIGN KEYS FROM t; | ALTER TABLE t DROP FOREIGN KEY fk;
